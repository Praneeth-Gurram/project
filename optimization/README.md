# SupplyPrescript Optimization Module

This module provides the prescriptive analytics engine for the SupplyPrescript project.

## Objective

Convert shipment delay predictions generated by the XGBoost model into optimal business decisions using Linear Programming (PuLP).

## Planned Components

- Business Configuration
- Optimization Engine
- Constraint Validation
- Recommendation Generator
- Decision Audit
- Closed-Loop Feedback

The module is intentionally developed independently from the backend so it can later be integrated with FastAPI.
